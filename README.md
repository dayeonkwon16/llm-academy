# llm-academy

부산 리테일 분석 학습 폴더입니다.

```
llm-academy/
├─ CLAUDE.md          # 나는 누구 · 6주 목표 · 선호 · 규칙
├─ README.md          # 이 파일: 폴더 구조 요약
├─ keyword-map.md     # 키워드 맵
├─ SOURCE.md          # inputs/ 데이터 출처
├─ inputs/            # 원본 CSV (열어서 다시 저장하지 말 것)
├─ prompts/           # 프롬프트 (01-keyword-map.md)
├─ examples/          # before-after 예시
└─ research/          # 리서치 노트 (_note-template.md 복사해서 작성)
```

- `inputs/` 숫자는 반올림·수정하지 않습니다. 출처는 `SOURCE.md`를 봅니다.
- 새 노트는 `research/_note-template.md`를 복사해 `YYYY-MM-DD-주제.md`로 만듭니다.
